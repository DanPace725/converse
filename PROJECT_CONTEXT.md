# Converse project context

Updated 2026-10-04. Mutable project state. [Usage](public/app-guide.md) · [Development method](docs/DEVELOPMENT_METHOD.md) · [Archive](docs/archive/README.md)

## Current capabilities

- Embedding-assisted Context/Agent history and automatic-memory activation: OpenAI vectors with persistent Neon pgvector search, bounded lazy indexing, keyword/semantic fusion, version/removal/suppression gates and explicit native usage/fallback. No embedding calls on saved-chat opening or manual edits. Source implementation/migration and native smoke passed locally; production pgvector migration/deployment remain unapplied after the disposable Neon test credential was rejected. [Contracts](../CLA/conclave/docs/EMBEDDINGS.md)
- Hosting efficiency: saved views now reuse the next-request calculation; optional aggregate load diagnostics separate database/hydration/view work. The offline probe shows most warm-read work remains in hydration/view calculation. [Plan and evidence](docs/HOSTING_PLAN.md)

- Unified model memory controls: `read_memory` pages both stores with revision checks; `suppress_memory` atomically suppresses automatic entries/retires named state when the current human request authorizes each target, immediately refreshing Context/Agent projections. Named memory details display effective status. Single-file atomic patch batches preserve unmatched text and require current-version readback. Shadow stage profiles and scoped history read caching expose/reduce local controller overhead. [Implementation and validation](docs/archive/2026-10-03/memory-tools.md)

- Automatic conversation-local memory in Context/Agent: quote-safe explicit commitments/corrections, narrowly targeted numeric USD budget revisions, bounded unresolved candidate extraction, event-backed correction/suppression history, source/dependency invalidation, scope-aware frozen activation and model-state authority gates. The Memory tab shows sources, authority, status, scope, previous versions and persistent capture issues, and copies an inspection snapshot. Edit and Don't use this/Use this again make no model calls. Explicit human-authorized named-state retirement preserves history; tool receipts report effective status. Binding overflow is explicit. [Implementation](docs/archive/2026-10-03/automatic-memory.md), [priority repairs](docs/archive/2026-10-03/memory-priority-repairs.md)

- Opt-in CLP evidence broker: versioned frame validation, immutable source-origin/lineage declarations and records, support/refute/supersede links, conservative independent-source floors, scoped/paged queries and per-result explanations. Thin/refuted/unmeasured claims remain unresolved. Library/API and read-only model tool; SQLite/Neon use existing events. [Usage and limits](docs/CLP_BROKER.md)

- Conclave engine authority is the Conclave repository. Providers, agents, workspaces, web tools, context controls, persistence, and shared resources migrate here with a source-commit/hash manifest; parity checks reject downstream drift. Application UI/deployment remain here. [Engine boundary](lib/conclave/VENDORED.md)

- Installable browser app with responsive UI, offline shell, sanitized Markdown and LaTeX, raw Markdown copy, saved chats, automatic titles, and linked user-message revisions.
- Chat: GPT, Claude, and Gemini share attributed history and can reply in parallel. Storage is on the device.
- Chat/Context/Agent prompts explain shared conversations across model switches: engage with earlier models' contributions and preserve authorship, clarifying identity when requested or relevant instead of routinely interrupting the discussion.
- Context: GPT or Claude uses Conclave's persistent source history, editable working projection, named state, retrieval, offloading, compaction, and source lineage. Provider/model identity follows each reply and source.
- Web search/pages: GPT/Claude Context and Agent modes use native search with existing keys and the selected model. `web_fetch` reads public HTTP pages directly, saves complete responses/extracted text, and returns text before Conclave manages older observed receipts. Exact source text remains retrievable; oversized requests can page it. Search/fetch quotas and Agent limits apply. Live native GPT/Claude searches and a direct Node.js page fetch passed locally. JavaScript rendering, PDF extraction and hosted verification remain unapplied.
- Agent: browser-driven, checkpointed tool work with Stop/Resume, bounded automatic testing allowances, readable failures, and duplicate-step protection. Stop immediately cancels the active request, skips remaining tools and calls, discards unfinished display text, and saves a stopped checkpoint with completed actions retained. Cancelled runs do not trigger title generation. Each response can execute 16 sequential tool calls; larger batches return saved errors for a later split.
- Workspace: versioned text documents, uploads, downloads, exact patches, manual context/state edits, reversible user removal/restoration, and current-version readback checks. Uploads and manual saves make no model calls. Tools calculate arithmetic and complete formulas.
- Context controls: stable S/E references, protection inspection, state-key relationships, cached selector decisions, local periodic timing checks, bounded semantic rewriting, and deterministic fallback. Context pressure tries routine source pointers before paid selection. New tool loops hold a stable projection until the next turn, explicit refresh, or logged guard refresh. Claude caching and signed continuation are supported.
- Request management: settled state precedes the recent tail; workspace views use short current-version excerpts, completed write arguments and repeated/superseded pages become retrievable pointers. Claude restarts redundant signed histories rather than rewriting them. Observed cache reads/writes select the settled-prefix breakpoint or growing tail.
- Local economics prices keeping context, specific pointer batches and proposed summary requests using the dated rate snapshot and complete serialized native-input estimates. Costs include cache/tier uncertainty and zero-to-full-batch recovery assumptions. First-use summary pricing needs no prior compaction call. Choices remain in shadow mode with only the pending next request as the horizon; no cost-only mutations or paid periodic timing reviews. Telemetry exposes candidates, component intervals, assumptions and exclusions. Pressure guards and explicit compaction remain available.
- Context forecast reconciliation: native prefix/age traces, reported cache buckets, request-linked input-cost comparisons and cached local evaluations with byte/time allowances. Estimator and optional telemetry failures fall back to keep without stopping answers. The source repository supplies a bounded, isolated previous-policy/current live runner. [Implementation and live evidence](docs/archive/2026-10-03/context-cost-controller-v3.md)
- Bounded ingress/delegation: focused document excerpts, bulk tool-receipt pointers, exact current-file pages, hybrid embedding/keyword retrieval, cached Jev shortlist reranking and chat-document classification, with deterministic fallback. Classification never promotes a partial document into named state; agent attachment ingress remains deterministic. Jev delegates rank/classify only and cannot execute tools or write artifacts.
- Inspection: one Workspace panel (Files, Context, Memory). The Context tab holds the garden map and replay, a per-part breakdown of the current/last request with drill-in to each piece and the reported remainder the local count does not explain, a full-history line on the same local basis, and activity paging/filters. Also shared user/model guide, readable provider reasoning summaries, full-request comparisons, local tokenization, explicit provider counts, and separate reported usage and byte guards.
- Persistence: local SQLite fallback or hosted Neon events/snapshots with leases and fenced writes. Vercel deployment is self-contained. App access uses a password.
- Timestamped Markdown/canonical JSON exports retain provenance and audit history. Shared cost reporting separates purposes, cache buckets, partial usage, and unpriced calls.

- Calibrate economic horizons, observed cache boundaries and delegation gates on matched long tasks. Current estimates and two synthetic retrieval/two ingress cases do not establish general savings or quality gains. Expand document classification beyond the first excerpt and add it to agent attachment ingress within run limits if useful.
- Calibrate the implemented shadow cost controller's cache boundaries, summary/recovery bounds and continuation forecasts, then test matched long live tasks before enabling automatic cost-triggered mutations. Bounded toy comparisons and request reconciliation are implemented. The current one-request estimate does not optimize future timing or establish savings. - Run fresh matched long-task trials; score source recovery, corrected decisions, numerical intermediates, current-version precedence, completion, output exhaustion, and total cost.
- Retrieval: exact phrases, author/source/sequence filters, explicit missing ranges, source-first ranking, active-context indicators, heading/TOC lookup, and search within files.
- Import: split transcript uploads into attributed sections; add JSON import and portable database restore.
- State: resolved/archive lifecycle, last-confirmed/proposal status, revision-conflict diffs, and model/user pin controls.
- Memory: embedding-assisted semantic correction targeting, episode consolidation, learned controller/utility policies, resumption packets and broader tool/document capture remain unapplied. Context topic/objective boundaries are not inferred. Image sharing and cross-chat features are deferred; cross-chat memory still needs individual ownership/access.
- Workspace: rename, version diffs, model scratch-file lifecycle, and private model workspaces with explicit artifact handoffs.
- Evaluate longer search/page tasks and live model source fidelity after compaction; hosted verification, JavaScript rendering and PDF extraction remain open. Explicit cross-conversation memory with ownership and corrections; semantic quality calibration and durable indexing jobs.
- Agent status messages that continue a run, completion checklists, isolated execution, and durable unattended workers.
- Permanent erasure across sources, snapshots, copies, backups, and exports; multi-user identity. Neon Auth is provisioned but not connected to the app.
- Light theme and composer model pickers. These and the larger design ideas remain proposals.
