# Issue #10 — panel sizing and streaming

Implemented and validated locally on October 1, 2026 for [GitHub issue #10](https://github.com/DanPace725/converse/issues/10). Changes are in the working tree; they have not been committed, pushed or deployed.

## Behavior

- Desktop Chats, Workspace, Settings and Context garden have draggable width handles. Settings also has a height handle. Focus a handle and use the arrow keys (10 pixels, or 50 with Shift); Home resets it. Sizes persist in local storage, respect screen bounds and preserve space for the conversation. Phone layouts retain their drawers and hide the resize controls.
- Workspace Context and State sections show their full text when expanded and use the panel's normal scrolling area. The old 220-pixel nested list limit and 160-character preview cutoff are removed. Settings can use the available height above the composer, and the selected Context preview has more vertical space.
- Context and Agent modes now stream GPT and Claude text. Task calls replace provisional previews as they continue through tools. Only the completed, saved answer enters the transcript and exports; failures and missing completion events never promote a partial answer to history. Context selection, compaction, tool execution and durable checkpoints retain their existing behavior.
- Existing JSON clients remain supported. Streaming clients receive NDJSON previews, periodic keep-alives and a final saved view. Hosted code returns that view only after the repository finishes persisting the turn/checkpoint. A disconnected browser does not replay or abandon a possibly executed tool step; reload to inspect saved progress.
- No packages or database migrations were added. The offline shell version includes the resize script.

The provider adapters follow the [OpenAI streaming event contract](https://developers.openai.com/api/docs/guides/streaming-responses) and [Claude Messages streaming contract](https://platform.claude.com/docs/en/build-with-claude/streaming). Complete tool arguments, reasoning continuation items, provider identity and reported usage are retained; Claude signed thinking stays out of the text preview. The inference audit records whether streaming was requested.

Browser checks use Microsoft Edge with desktop and phone-sized viewports, real local HTTP/service/storage, and scripted model providers. New checks prove incremental display before persistence for both assistants and both modes, replacement after tool calls, failure recovery and reload, full Context text, mouse/keyboard resize, width restoration after reload, resizing at the desktop breakpoint, and phone bounds. Adapter checks split SSE across arbitrary UTF-8 and CRLF boundaries, reconstruct Claude tool JSON/signatures/cache usage, and reject missing terminal events.

Live paid-provider streaming, the disposable Neon branch and hosted Vercel streaming have not been exercised for this change. The existing hosted persistence/deadline wiring was reviewed. During ordinary Chat test teardown, the Windows test server remained running after all cases finished; stopping that exact test-server process let Playwright complete successfully with exit code 0.
