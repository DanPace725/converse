# Automatic memory in Converse

2026-10-03. Conclave is the implementation authority. Converse migrated 66 managed runtime/resource files from source commit `41dfe2d05708ca8d1cf5662fd490652cc24dfce7`; the migration manifest and `--check` matched. [Technical usage and limits](https://github.com/DanPace725/conclave/blob/41dfe2d05708ca8d1cf5662fd490652cc24dfce7/docs/AUTOMATIC_MEMORY.md)

Context and Agent now capture conversation-local user commitments/corrections before answering. Explicit clauses preserve exact quantities, units and conditions. Less structured durable input can use one bounded candidate-extraction call; its interpretations remain unresolved and its usage appears under `memory-extraction`. The selected task model does not gain memory-controller permissions. Named model state passes the same authority gate rather than promoting arithmetic into a user constraint.

The ledger persists independently of editable context snapshots. Repeated exact human clauses share a head without gaining independent support. Corrections preserve old versions; ambiguous alternatives remain contested. Selection carries declared dependencies and binding constraints before optional lexical memories, uses a bounded allowance, and freezes during tool exchanges. Overflow is explicit while inspection remains usable. Agent-start records are scoped to that objective; Context records remain conversation-local.

The existing Memory tab shows automatic records alongside manual state. Open an entry for its source, authority, resolution/lifecycle, scope, selection status and previous versions. Edit records a human correction with no inference. Don't use this suppresses the record and its linked source/context passages from model lookup; Use this again rechecks eligibility. Human inspection and exports preserve history. User revisions/current file changes/removal invalidate dependent records on replay. Generic PostgreSQL events use existing leases and fenced sequence/revision writes; no database migration or worker was added.

Validation:

- Conclave: 200 passes, one optional saved-export replay skipped, plus syntax checks. Thirteen focused memory fixtures cover authority, exact conditions/units, duplicate/correction heads, restart, source invalidation and dependency closure, suppression, capacity/frozen projections, paid capture failures/retries, Agent cancellation/scope and fresh PostgreSQL instances. A timing-sensitive shadow-estimator fixture passed in isolation and in the full run at concurrency two.
- Converse: 186 backend passes, one live Neon check skipped; syntax and 66-file engine parity passed. The first run hit Windows sandbox temp rename failures. The passing run placed TEMP/TMP under the ignored workspace test directory.
- Browser: all 60 desktop/mobile checks passed, including sources/history/edit/suppression/restoration/reload with no extra model calls for manual actions. Edge could not launch in the Windows sandbox; the passing run used isolated test profiles outside it. Fixtures establish these invariants, not general answer-quality or savings. Capture is conservative, model candidates are unresolved, and Context topic boundaries are not inferred. Ordinary browser Chat, cross-chat memory, episode consolidation, learned policies, resumption packets and unattended workers remain outside this increment.
